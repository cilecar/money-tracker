# Долги — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Разделение покупок («мне должны») и «за меня заплатили» («я должен») с честной аналитикой
(только моя доля) и погашениями, двигающими баланс счёта.

**Architecture:** Три новые таблицы (`person`, `expense_share`, `paid_for_me`), существующие не меняются.
Доли и «за меня заплатили» превращаются в `Expense` со знаком (как `Refund.asNegativeExpense()`) и идут
через существующие формулы `Total`/`Analytics`/`BudgetProgress`/`MonthSummary`. Погашение — четыре
колонки в строке долга; баланс видит только погашения.

**Tech Stack:** Kotlin, Room (KSP, exportSchema), Hilt, Jetpack Compose (Material 3), kotlinx.serialization,
JUnit 4 (`:domain` — чистый JVM), Robolectric (`:app`).

**Spec:** `docs/superpowers/specs/2026-11-01-debts-design.md`

## Global Constraints

- `:domain` — чистый Kotlin/JVM, тесты plain JUnit без Robolectric. Gradle на JDK 21.
- Деньги — `Money` в минорных единицах; у всех валют 2 знака. Суммы погашения — в валюте счёта погашения.
- Каждая строка UI — в `app/src/main/res/values/strings.xml` (ru) и `values-en/strings.xml` (en).
- После смены версии БД: `./gradlew clean` и сборка с `--no-build-cache`; `app/schemas/.../1.json`–`4.json` не должны измениться (`git diff --stat app/schemas`).
- Проверка этапа: `./gradlew assembleDebug :domain:test :app:testDebugUnitTest` — всё зелёное; затем коммит, `./gradlew --stop`, **остановка до OK пользователя**.
- Комментарии в коде — по-русски, в стиле существующего кода (объясняют «почему»).
- Коммиты — в ветку `feature/debts`, сообщения по-русски, с трейлерами `Co-Authored-By` / `Claude-Session`.

## Review Focus

1. **«Отменить» после удаления расхода с долями** — доли (включая погашенные) возвращаются с теми же id → тест в Task 5.
2. **Смена суммы/валюты расхода с долями без открытия панели** (`shares = null`) — валидируется против сохранённых долей, а не пропускается → тест в Task 3.
3. **Расход без курса (офлайн) с долями** — доля попадает в `withoutRates`, а после `FillPendingRates` расхода считается автоматически → тест в Task 7.
4. **Удаление категории, на которую ссылается `paid_for_me`** — записи переносятся, а не падает FK → тест в Task 5.
5. **Погашение раньше `opening_date` счёта / удаление счёта с погашениями** — не входит в баланс / счёт считается «с операциями» → тесты в Task 9.
